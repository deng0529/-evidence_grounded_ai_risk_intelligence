# M8.1 current UI behavior

This document supersedes the M8 historical form/display descriptions for the
changes in this patch. Frozen six-variable v1.2 calculations are unchanged.

- Company/year selection exposes names rather than internal assessment/model IDs.
- Display uses two decimal places without changing persisted Decimal values.
- Changing the selected company/year/context clears the previously displayed view.
- New assessment uses company number, assessment date and reporting year, plus an
  explicit source refresh option. Server defaults bound accounts retrieval to five documents.
- Exact company/year/date result reuse occurs before constructing ingestion clients.
  Changing the assessment date does not reuse a different date silently.
- GPT model names and exact document-download hosts are administrator YAML settings
  at `src/risk_intelligence/services/config/models.yaml`; keys stay in secure environment configuration.
- Missing optional OpenAI credentials leaves deterministic extraction enabled.
- The optional summary button lets an LLM order a complete catalog of six verified
  sentences. The model cannot add facts or omit indicators; returned arbitrary prose
  is never displayed. A failed request does not discard the assessment.
- Source/evidence drill-down remains the existing M7 tree. Unknown dominance receives
  an explicit uncertainty description; it is never silently classified as low risk.

The default download host list is intentionally empty pending actual provider
redirect evidence. Wiring an allowlist is not proof that document retrieval works.

Acceptance is still open: upload lacked original examples required by five existing
tests, and two pilot companies have not completed live verification in this environment.
See CURRENT_HANDOFF.md for exact resumption steps and M9 prerequisites.
